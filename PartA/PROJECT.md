# s25-lab13
Lab 13 AI-Assisted Software Construction

## Сонгосон сэдэв : Markdown Note-Taking App
Хайлт, таг, PDF export үйлдлүүдийг дэмждэг browser болон app дээр суурилсан local орчинд ажиллах Application хөгжүүлэх.

## Хураангуй
Хэрэглэгч нь тэмдэглэл үүсгэх, унших, засварлах, устгах үйлдлүүдийг editor ашиглан гүйцэтгэнэ. Тэмдэглэлийг таг ашиглан зохион байгуулах, PDF болгон export-лох, дундаас нь текст хайх боломжтой. 

## Хамрах Хүрээ

- **Note CRUD** — тэмдэглэл үүсгэх, унших, засварлах, устгах
- **Markdown rendering** — Текстийн форматтийг харуулах(bold, italic, color, etc)
- **Full-text search** — Гарчиг болон эх биеийн текстийг шалгадаг, олдсон бол тодруулдаг
- **Tag system** — тэмдэглэл бүрд таг нэмэх, тагаар шүүх
- **PDF export** — Нэг эсвэл олон тэмдэглэлийг PDF болгох.
- **Local** — Бүх үйл ажиллагаа back-end шаардахгүй байна.
- **Responsive UI** — desktop болон tablet дээр ажиллах
